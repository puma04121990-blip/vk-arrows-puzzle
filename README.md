# Arrow Pulse — головоломка для VK Games

Игра на Phaser 3: убирай стрелки, если путь в их направлении свободен.

## Что уже сделано под VK Games

- ✅ `VKWebAppInit`
- ✅ `VKWebAppSetViewSettings` (тёмный статус-бар)
- ✅ Получение имени пользователя
- ✅ **Синхронизация прогресса между платформами** (п. 2.3.8): `VKWebAppStorage` (привязка к `user_id`) + localStorage-кэш
- ✅ Загрузка облачного прогресса **до** показа меню (Boot ждёт `loadProgress`)
- ✅ Merge «лучший прогресс» (maxLevel / звёзды / достижения) при стыковке local + cloud
- ✅ Кнопки «Продолжить» / «Сначала»
- ✅ Правила игры на стартовом экране
- ✅ Портретная ориентация, без скролла и зума
- ✅ Обработка сворачивания/возврата (visibility) + flush прогресса
- ✅ Корректная работа в iframe WebView VK
- ✅ 50 уровней с ростом сложности

## Локальный запуск

```bash
python -m http.server 8080
# открыть http://localhost:8080
```

На Android: Simple HTTP Server → Root folder = папка проекта → `http://127.0.0.1:8080`

## Публикация в VK Games — чеклист

### 1. Создать приложение
1. Зайти на [dev.vk.com](https://dev.vk.com)
2. Создать приложение → тип **Игра / VK Games**
3. Указать название, иконки, скриншоты

### 2. Хостинг
Варианты:
- Хостинг статики VK (в кабинете игры)
- GitHub Pages / любой HTTPS-хостинг

В настройках приложения указать URL `index.html`.

### 3. Заполнить карточку
- **Название:** Arrow Pulse (или своё)
- **Короткое описание:** Убери все стрелки с поля. Тапай только по тем, у которых путь свободен.
- **Полное описание:** механика + 50 уровней
- **Возраст:** 0+ / 6+
- **Скриншоты:** меню, геймплей, экран победы (портрет)
- **Правовые документы:** при необходимости политика / пользовательское соглашение

### 4. Перед модерацией проверить
- [ ] Игра открывается внутри клиента VK (не только в браузере)
- [ ] Нет белых экранов / ошибок в консоли
- [ ] Кнопка «Играть» сразу запускает геймплей
- [ ] Правила понятны с первого экрана
- [ ] Прогресс сохраняется после перезапуска
- [ ] **Кросс-платформа (2.3.8):** пройти уровень на Web → открыть на Android/iOS под тем же аккаунтом → «Продолжить» / открытые уровни на месте
- [ ] В кабинете указано **сообщество** для связи (не только личная страница) — то же, что в `js/support.js`
- [ ] В `js/support.js` прописаны реальные `communityUrl` и `email`
- [ ] Нет внешней рекламы и редиректов
- [ ] Работает на слабом Android

### 5. Отправить на модерацию
В кабинете приложения → модерация / публикация в каталог.
