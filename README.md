# Arrow Pulse — головоломка для VK Games

Игра на Phaser 3: убирай стрелки, если путь в их направлении свободен.

**Игра в VK:** [https://puma04121990-blip.github.io/vk-arrows-puzzle/](https://puma04121990-blip.github.io/vk-arrows-puzzle/)

## Исправления модерации (2026-08-29)

- Экран согласия: кнопка «Принимаю» больше не перекрывает текст
- Меню и «Правовая»: облако VK, кнопки и подвал не наезжают друг на друга
- Игра заполняет iframe VK и в портрете, и в ландшафте
- Callback платежей возвращает `item_id`, числовой `price` и `app_order_id`

### Что осталось сделать в кабинете VK (только вы)

Подробно, с картинками-шагами для новичка: [`server/README.md`](server/README.md).

Кратко:
1. URL игры: `https://puma04121990-blip.github.io/vk-arrows-puzzle/`
2. Подключить тот же GitHub-репозиторий к [Vercel](https://vercel.com) и задать переменную `VK_APP_SECRET` = **Защищённый ключ** из настроек приложения VK.
3. В кабинете VK, раздел **Платежи**, поле **Адрес обратного вызова**:
   `https://ВАШ-ДОМЕН.vercel.app/vk/payments`


На Android: Simple HTTP Server → Root folder = папка проекта → `http://127.0.0.1:8080`

## Публикация в VK Games — чеклист

### 1. Создать приложение
1. Зайти на [dev.vk.com](https://dev.vk.com)
2. Создать приложение → тип **Игра / VK Games**
3. Указать название, иконки, скриншоты

### 2. Хостинг
Варианты:
- Хостинг статики VK (в кабинете игры)
- GitHub Pages / любой HTTPS-хостинг

В настройках приложения указать URL `index.html`.

### 3. Заполнить карточку
- **Название:** Arrow Pulse (или своё)
- **Короткое описание:** Убери все стрелки с поля. Тапай только по тем, у которых путь свободен.
- **Полное описание:** механика + 50 уровней
- **Возраст:** 0+ / 6+
- **Скриншоты:** меню, геймплей, экран победы (портрет)
- **Правовые документы:** при необходимости политика / пользовательское соглашение

### 4. Перед модерацией проверить
- [ ] Игра открывается внутри клиента VK (не только в браузере)
- [ ] Нет белых экранов / ошибок в консоли
- [ ] Кнопка «Играть» сразу запускает геймплей
- [ ] Правила понятны с первого экрана
- [ ] Прогресс сохраняется после перезапуска
- [ ] **Кросс-платформа (2.3.8):** пройти уровень на Web → открыть на Android/iOS под тем же аккаунтом → «Продолжить» / открытые уровни на месте
- [ ] В кабинете указано **сообщество** для связи (не только личная страница) — то же, что в `js/support.js`
- [ ] В `js/support.js` прописаны реальные `communityUrl` и `email`
- [ ] Нет внешней рекламы и редиректов
- [ ] Работает на слабом Android

### 5. Подключить покупки за голоса VK

Клиентская часть магазина вызывает `VKWebAppShowOrderBox` с item ID товара. Для реальных покупок необходимо дополнительно развернуть публичный HTTPS callback-сервер из [`server/vk-payments-callback.js`](server/vk-payments-callback.js), задать на сервере `VK_APP_SECRET` и указать URL `/vk/payments` в настройках приложения VK.

Перед публикацией проверить:

- [ ] callback отвечает по HTTPS и доступен извне;
- [ ] в окружении сервера задан `VK_APP_SECRET`, секрет не находится в GitHub;
- [ ] callback обрабатывает `get_item` и `order_status_change`;
- [ ] тестировщики добавлены в список Payments tester VK;
- [ ] в VK test mode проверены успешная оплата, отмена, неверный товар и повторное уведомление;
- [ ] после подтверждённого `status: success` товар выдан ровно один раз для конкретного заказа;
- [ ] журнал заказов хранится на постоянном диске или заменён на транзакционную БД при нескольких экземплярах сервера.

Подробная инструкция и таблица товарных ID находятся в [`server/README.md`](server/README.md).

### 6. Отправить на модерацию
В кабинете приложения → модерация / публикация в каталог.
