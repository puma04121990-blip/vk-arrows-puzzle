# 📱 Как запустить и тестировать игру с Android-телефона

## Способ 1 — Через компьютер (рекомендуется)

1. На компьютере в папке проекта выполни:

```bash
python -m http.server 8080
```

Или если установлен Node.js:

```bash
npx serve -p 8080
```

2. Узнай свой локальный IP:
   - Windows: `ipconfig` → IPv4-адрес
   - macOS/Linux: `ifconfig` или `ip a`

3. Телефон и компьютер должны быть в **одной Wi-Fi сети**.

4. На телефоне открой Chrome и введи:
   ```
   http://192.168.1.XX:8080
   ```
   (подставь свой IP)

Игра откроется в полноэкранном режиме и отлично работает на тачскрине.

---

## Способ 2 — Полностью на телефоне (без компа)

1. Скачай проект как ZIP с GitHub и распакуй на телефон (в Downloads или Documents).
2. Установи одно из приложений:
   - **Simple HTTP Server** (Google Play)
   - **KSWEB**
   - **Termux** + `pkg install python` и `python -m http.server 8080`
3. В приложении укажи папку с `index.html` и запусти сервер.
4. Открой в браузере `http://127.0.0.1:8080` или адрес, который покажет приложение.

---

## Важно
- Phaser подключён локально (`vendor/phaser.min.js`) — для геймплея CDN не нужен. Phaser и VK Bridge лежат локально в `vendor/` — внешние CDN не нужны.
- На Android лучше всего работает Chrome / Samsung Internet.
