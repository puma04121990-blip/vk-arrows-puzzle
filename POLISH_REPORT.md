# Arrow Pulse — аудит и полировка

## Результат

Проект проанализирован как offline-friendly HTML5-игра на Phaser 3 с локальными копиями Phaser и VK Bridge. Улучшения внесены без перехода на сборщик и без удаления существующей VK Storage-синхронизации.

## Что доработано

| Область | Изменение |
|---|---|
| Типографика | Добавлен стек Manrope с системными fallback-шрифтами, повышена читаемость кириллицы, сохранены контрастные цвета и крупные зоны нажатия. |
| Кнопки | Унифицированы hover/press-состояния, добавлена короткая звуковая обратная связь, сохранены вторичная и основная иерархии. |
| Аудио | Реализованы раздельные эффекты и фоновая процедурная музыка без внешних файлов; настройки сохраняются отдельно, звук автоматически ставится на паузу при сворачивании. |
| HUD | В игровом поле добавлен индикатор цепочки безопасных ходов и отображение мастерства. |
| Новая механика | Последовательные безопасные ходы формируют цепочку. Цепочка требует поддержания темпа; после достижения цели игрок получает небольшой бонус времени и усиливающийся аудиовизуальный feedback. Ошибка или потеря темпа сбрасывает цепочку. |
| Прогрессия | Добавлены рекорды комбо, число завершённых цепочек и мастерство по уровням. Данные сохраняются в локальном и компактном VK Storage payload. |
| Достижения | Добавлены цели «Ритм поля» за цепочку из 5 ходов и «Пульс мастера» за цепочку из 10 ходов. |
| Экран победы | Добавлен блок результата цепочки и сообщение о достижении мастерства. |
| Адаптация | Обновлена оболочка для safe-area, landscape/portrait, reduced-motion и web-фокус-состояний; существующая Phaser FIT/CENTER_BOTH схема сохранена. |

## Проверки

Проведены следующие проверки:

1. Выполнен `node --check` для всех JavaScript-файлов проекта.
2. Выполнена проверка `git diff --check`.
3. Проверена загрузка `index.html` через локальный HTTP-сервер.
4. Подтверждено наличие локальных Phaser, VK Bridge и logo-ассетов.
5. В браузере проверены onboarding, главное меню, первый уровень, отображение музыкальных контролов, HUD цепочки и обработка безопасного хода.
6. В консоли браузера после запуска уровня и безопасного хода runtime-ошибок игрового кода не обнаружено.

## Дополнительный video-driven аудит

По видеозаписи `Стрелки_02.mp4` отдельно проверены переходы меню, уровни, стили, магазин, достижения, помощь, ежедневный режим, победа и поражение. Критичными наблюдениями были избыточная плотность текстовой инструкции, пустые боковые области в широком Web-окне, неочевидное значение «Мастерства», негативное состояние кнопки подсказки при нулевом запасе и недостаточно заметный feedback ошибки/комбо.

Внедрены следующие исправления: при нулевых подсказках кнопка теперь явно ведёт в магазин; при столкновении появляются частицы и лёгкая screen shake-анимация; сильное комбо получает дополнительный визуальный feedback; раздел «Как играть» объясняет цепочку, темп и влияние мастерства; для landscape добавлены декоративные боковые поля; введён cache-busting `v=91`; локальный Web-запуск больше не ошибочно инициирует VK bridge, а общий fallback защищает Boot от медленного bridge/storage.

Полный исходный отчёт видеоанализа сохранён в `VIDEO_AUDIT_2026-08-16.md`.

## Повторный video-driven аудит: `Стрелки_03.mp4`

Вторая видеопроверка подтвердила сильную читаемость базового UI и качество спокойного аудиосопровождения, но обнаружила критические проблемы: несуществующую ссылку VK-сообщества, отображение `Время: 0 сек` после прохождения, слишком маленькие показатели цепочки и ошибок в landscape, а также статичность экрана победы.

В этой итерации реальное время забега считается от старта сцены, поэтому экран победы больше не зависит от дискретного 200-мс тика таймера. В landscape свободные боковые зоны теперь заняты крупными функциональными панелями «Цепочка» и «Ошибки». На экран победы добавлен анимированный прогресс-бар мастерства. Первые три уровня получили интерактивный coach-mark: безопасная стрелка подсвечивается, неверные действия на этапе обучения не наказываются, а после двух успешных ходов управление возвращается игроку.

Неработающий URL `vk.com/puls_strelok` удалён из пользовательского интерфейса: экран поддержки показывает рабочий e-mail и не ведёт на страницу 404. Для модерации VK Games владелец должен до публикации указать в `js/support.js` собственный созданный и публичный URL сообщества, а также тот же URL в кабинете разработчика. Полный первичный отчёт сохранён в `VIDEO_AUDIT_2026-08-16_02.md`.

## UI, подсказки и Web Audio — финальная корректировка

По приложенным скриншотам устранены три класса визуальных конфликтов. Экран достижений теперь использует маску scroll-области и увеличенный верхний отступ, поэтому первая карточка не пересекается с заголовком и счётчиком. В игровом landscape-HUD боковые панели вычисляются исключительно за пределами рамки board; если ширины для них недостаточно, игра переключается на компактный чип цепочки над полем, не перекрывая сетку. Для portrait и landscape рамка игрового поля рассчитывается вместе с собственными резервами под header и нижние действия.

Механика подсказок обновлена: при нулевом балансе игрок получает переход в магазин; при положительном балансе подсказка расходуется только после нахождения существующей доступной стрелки; при обучении используется текущая coach-mark цель без расхода платной подсказки; несколько колец подсветки не накапливаются. Уведомление подсказки перенесено в безопасную область между полем и нижними кнопками.

Аудиоуправление вынесено из угловых иконок в отдельную сцену «Настройки» с переключателями музыки и эффектов, тестовой кнопкой и сохранением параметров. Web Audio переработан для браузерного autoplay: первый реальный клик/тап/клавиша разблокирует AudioContext, музыка запускается только после состояния `running`, а после возвращения на вкладку и после выключения/повторного включения фона её цикл надёжно возобновляется.

## Web-оболочка и магазин — витринная итерация

Прозрачные боковые псевдоэлементы и desktop-градиент удалены из CSS-оболочки. Веб-версия теперь использует единый нейтральный фон без вертикальных линий за игровым canvas. Из настроек удалена избыточная кнопка «Проверить звук»: управление остаётся только через два понятных переключателя музыки и эффектов.

Магазин переработан как витрина: список карточек маскируется в безопасной области между header и footer; последняя одиночная карточка «Все стили» занимает всю строку на landscape; CTA увеличены; статус опечатки «КУТО» заменён на «КУПЛЕНО». Временный бонус ×2 звёзды получает состояние «АКТИВНО» и защищён от повторной оплаты как в UI, так и в `buyWithVotes`. В локальном Web-сценарии проверены начисление трёх подсказок, обновление счётчика, выдача ×2 звёзд и отклонение второй покупки как `already_active`.

## Навигация меню

Пункт «ПОДДЕРЖКА» удалён из главного меню по итоговой UX-проверке. Сцену поддержки и её рабочий e-mail это не удаляет из проекта, но прямой пункт больше не занимает место в основной навигации. Список оставшихся кнопок автоматически пересчитывает шаг по доступной высоте, поэтому меню сохраняет равномерную компоновку в Web, portrait и landscape.

## Повторное использование подсказок

Исправлен блокирующий сценарий, при котором `_hintBusy` удерживал кнопку до завершения длинной анимации и создавал впечатление одноразовой подсказки. Теперь используется только debounce 260 мс для защиты от случайного двойного тапа; после этого каждое нажатие ищет следующий доступный ход, удаляет предыдущую подсветку, запускает новую анимацию и списывает ровно одну подсказку. Проверены пять последовательных вызовов: баланс прошёл с 5 до 0 по одному за нажатие. Дополнительно проверен быстрый двойной тап: списалась только одна подсказка, а следующий вызов после debounce снова сработал.

## VK Payments and shop audit

The client payment path now accepts the VK Bridge confirmation shape `{ status: 'success', order_id }`, keeps compatibility with `success: true`, stores the last order identifier for diagnostics, and does not grant an item for cancel, unknown status, bridge error, or failed grant.

All seven products were tested in local Web test mode. The resulting state was 13 hints, 4 additional mistake slots, active double-stars, no-ads enabled, and one purchase count per item. Repeat attempts correctly returned `already_active` for double-stars and `already_owned` for no-ads and the skin pack. A mock VK response with `status: 'success'` granted 3 hints and stored `mock-order-1`; a `status: 'cancel'` response left the balance unchanged.

A dependency-free callback server was added at `server/vk-payments-callback.js`. It handles signed `get_item` and `order_status_change` POSTs, test-mode suffixes, invalid signatures, and a persistent test/live order journal. Integration tests returned product metadata, order confirmation, and error 10 for an invalid signature.
