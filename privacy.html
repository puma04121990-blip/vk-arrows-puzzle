Политика конфиденциальности

Игра «Пульс стрелок» · Дата: 01.08.2026

Настоящая Политика описывает, какие данные обрабатываются при использовании мини-приложения (игры) «Пульс стрелок» в экосистеме VK.

1. Кто обрабатывает данные

Разработчик (правообладатель) игры «Пульс стрелок». Игра распространяется через платформу VK (ВКонтакте).

2. Какие данные используются

  • Прогресс игры (пройденные уровни, звёзды, выбранный стиль стрелок, достижения) — сохраняется локально на устройстве пользователя (localStorage браузера / WebView).
  • Имя пользователя VK — только если платформа VK передаёт его через VK Bridge (VKWebAppGetUserInfo). Используется исключительно для персонального приветствия в меню. Не передаётся третьим лицам.
  • Игра не запрашивает доступ к друзьям, сообщениям, фотографиям, геолокации и другим чувствительным данным.

3. Цели обработки

  • сохранение игрового прогресса;
  • отображение приветствия;
  • обеспечение работы функций игры.

4. Передача третьим лицам

Персональные данные пользователей не продаются и не передаются третьим лицам в маркетинговых целях. Технические данные могут обрабатываться инфраструктурой VK в соответствии с правилами платформы VK.

5. Хранение

Локальные данные прогресса хранятся на устройстве пользователя до очистки данных браузера / приложения. Пользователь может сбросить прогресс, очистив данные сайта или хранилище WebView.

6. Права пользователя

Пользователь может прекратить использование игры в любой момент. Для удаления локальных данных достаточно очистить данные приложения / сайта.

7. Изменения политики

Актуальная версия Политики всегда доступна по этому адресу. Продолжение использования игры после обновления означает согласие с новой редакцией.

8. Контакты

По вопросам, связанным с персональными данными и работой игры, обращайтесь к разработчику через страницу приложения в VK.
