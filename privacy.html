Политика конфиденциальности

Мини-приложение / игра «Пульс стрелок» · Редакция от 12.08.2026

Настоящая Политика определяет порядок обработки информации о пользователях при использовании игры «Пульс стрелок» в экосистеме VK (ВКонтакте, VK Mini Apps / VK Games).

1. Оператор данных

Оператором в отношении данных, обрабатываемых непосредственно игрой, выступает разработчик мини-приложения «Пульс стрелок». Платформа VK обрабатывает данные в соответствии с собственными документами экосистемы VK.

2. Какие данные обрабатываются

  • Игровой прогресс — номер пройденных уровней, количество звёзд, достижения, выбранный стиль стрелок. Хранится локально (localStorage) и в облаке VK через VK Bridge API VKWebAppStorageSet / VKWebAppStorageGet. Облачное хранилище привязано к user_id аккаунта VK, поэтому прогресс синхронизируется между Android, iOS, Mob.Web и Web.
  • Имя (first_name) пользователя VK — может быть получено через VK Bridge (метод VKWebAppGetUserInfo) только для отображения приветствия в меню. Не сохраняется на внешних серверах разработчика.
  • Игра не собирает: номер телефона, email, геолокацию, список друзей, сообщения, фотографии, платёжные данные.
  • Игра не использует стороннюю аналитику и рекламные трекеры третьих лиц. Для монетизации может показываться нативная реклама платформы VK (VK Bridge Native Ads: rewarded и interstitial) — обработка рекламных показов выполняется инфраструктурой VK в соответствии с политиками VK.

3. Цели обработки

  • обеспечение работы игровых функций и сохранения прогресса;
  • синхронизация прогресса пользователя между платформами (п. 2.3.8 правил VK Mini Apps);
  • персонализация интерфейса (приветствие);
  • соблюдение требований платформы VK.

4. Правовые основания

Обработка осуществляется на основании использования сервиса пользователем (исполнение пользовательского соглашения) и, применительно к данным VK, — в рамках разрешений и правил платформы VK / VK ID.

5. Передача третьим лицам

Разработчик не продаёт и не передаёт персональные данные пользователей третьим лицам в коммерческих целях. Техническая обработка и облачное хранение прогресса выполняются инфраструктурой VK согласно Политике конфиденциальности VK и Политике конфиденциальности экосистемы VK.

6. Хранение и удаление

Локальный кэш прогресса хранится на устройстве до очистки данных браузера / WebView. Облачная копия хранится в VK Storage платформы и удаляется средствами платформы VK. Отдельной серверной базы персональных данных у разработчика нет.

7. Права пользователя

  • прекратить использование игры в любой момент;
  • удалить локальные данные, очистив хранилище приложения / сайта;
  • обратиться к разработчику по вопросам обработки данных через страницу приложения в VK.

8. Защита данных

Разработчик не размещает персональные данные на собственных серверах. Облачное хранение прогресса обеспечивается платформой VK. Безопасность среды исполнения обеспечивается платформой VK.

9. Изменения Политики

Актуальная редакция всегда доступна по текущему адресу. Существенные изменения отражаются обновлением даты редакции. Продолжение использования игры после публикации новой редакции означает согласие с ней.
